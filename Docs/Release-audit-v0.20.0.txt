Stroka 0.20.0 (23) - simpler publisher selection, 14 November 2026

The public setup now has two screens: pick publisher cards -> ready preview and Start ticker. Four mandatory onboarding steps were removed; the previous four-step SwiftUI view is excluded from production with the diagnostics condition. First launch shows six diverse suggestions without preselecting sources. Topics, search and browse-language filters change discovery only. Selected URLs remain selected when hidden by a filter; Selected only reviews the choices. Choose for me explicitly adds a bounded suggestion set, and More sources progressively expands the catalog. AI publishers remain discoverable under Technology. Custom Telegram/RSS names are optional and default to username/host.

Confirmation creates one feed from exactly the selected publishers. Branding and four looks are on the ready screen; markets, logos, translation and detailed appearance are optional. One chosen source is enough. Existing four-row controls remain available after setup. Existing profiles are unchanged during discovery/cancellation; confirmed configuration retains authored text and descriptive topic names. No network requests are initiated for a brand-new profile before final confirmation.
