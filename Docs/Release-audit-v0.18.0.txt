Stroka 0.18.0 (21) - local multiline update, 14 November 2026

Implemented: one to four independently selected rows. Each row can display a content topic, custom public RSS/Atom/Telegram sources, authored text or the shared market watchlist. First-row authored text, brand, publishers, instruments, languages and presets survive the update. Legacy two-row selection is preserved when it first becomes an explicit row configuration. Source language and keyword/length filters belong to the selected row; appearance, station blocks, playback, Russian translation and instrument watchlist remain shared.

Rendering: independent Core Animation surfaces inside the same native strip window. Fixed station and clock span every row. All text clips exactly at matching side seams. Information rows have equal weights; a market row has a slightly smaller weight. Three/four rows require at least 84/112 pt within the existing 180 pt cap. Existing narrow one/two-row settings remain supported. Adding rows does not add per-frame application timers. Occlusion, reduced motion and pause apply across the row tree.

Data: shared feed URLs are fetched once per refresh, with the existing four-request/5 MB transport limits. Cache entries retain source URL identity for row routing; cache size is bounded with per-source fairness. Original publication-date expiry is applied independently to all online rows. Offline collections remain timeless. No native X integration is included.

Checks: 17 multiline assertions passed, covering legacy migration, independent text, offline demand, four renderer instances, shared boundaries, complete strip partitioning, quote-only body changes, reduced motion, URL deduplication, mocked RSS delivery to separate rows, row-specific language/source isolation, 24-hour expiry, Codable persistence, draft cancellation, renderer removal and four information rows without markets. Additional checks passed: 42 compact, 48 desktop-edge, 25 simplified-setup and 20 feed-reliability assertions. The earlier self-test in this implementation run passed 101 assertions. Four-style strip snapshots and English/Russian four-row setup snapshots were inspected. Final production compilation includes a small row-specific empty-state correction after the diagnostic run.

LIMIT: the Mac desktop was locked (CGSSessionScreenIsLocked=1). Live four-row animation and pause acceptance were explicitly skipped, not counted as passes. No new CPU, energy or compositor-FPS result is claimed. Diagnostic benchmark cases for four information rows and three information rows plus markets are prepared for an unlocked desktop. Existing motion evidence from older releases does not establish the four-row result.
