Stroka 0.19.0 (22) - guided personal-feed setup, 14 November 2026

First launch now opens four steps: Interests, Sources, Rows, Appearance. Multiple selected interests become explicit publisher selections rather than one opaque preselected RSS pack. A user can review grouped publishers, select original languages and optional Russian translation, add public Telegram/RSS, combine all topics in one feed or distribute them across informational rows, optionally select market instruments/crypto, then choose station name/logo, four looks, corners, clock/date and top/bottom position.

All selected topics need an enabled source in the selected source languages. The setup explains missing sources/languages and blocks confirmation instead of silently dropping a topic. More than four topics are grouped while retaining every topic within the four-row limit. Duplicate publisher URLs are fetched once. Per-row topic titles and explicit custom-source selections are Codable. Original-date expiry and existing market timing semantics remain unchanged.

New profiles do not start source services before final confirmation. Completion is remembered. If initial setup is interrupted, the wizard opens again from the first step; unconfirmed choices remain in memory rather than being written over the live profile. Existing installations retain their profile and can opt into Build my feed. Editing and Cancel leave the profile untouched. Finish applies a reviewed draft and starts the ticker. Authored main messages remain available after creating a news profile. The About version now comes from bundle metadata.
