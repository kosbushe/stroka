# Roadmap

## Desktop beta

Keep the top/bottom personal ticker simple. Current code: Mac 0.23.1, height 45-180 pt. Finish long-session/sleep/wake/Intel/external-display/120 Hz and accessibility acceptance, signing/notarization and store preparation. No guaranteed deadline is set.

## Android TV receiver

The separate 0.2.2 receiver mirrors a running Mac. Continue video-app/DRM/remote/lifecycle acceptance and check the 45-point update on devices. A locally signed APK is not a Play release.

## iPhone + autonomous TV

The [Lab](Labs/Ecosystem/README.md) prepares QR → TV confirmation, common editor profiles, certificate pinning and a TV-owned RSS engine. Next: a real iOS build and iPhone 15 acceptance, physical complete pairing, long standalone playback, reconnect/DHCP/sleep tests, translation, logo transfer, full offline packs and market-provider parity. See [PARITY](Labs/Ecosystem/Docs/PARITY.md).

## Windows

A native Windows port is a future direction. Catalog JSON and protocol documentation are useful starting references; no Windows renderer/installer is included. Agree source/contribution terms before code reuse.

## Distribution

Select source-reuse terms, establish support operations, review providers for intended distribution/display, and complete platform signing and store requirements. GitHub beta publication does not imply App Store/Google Play acceptance.
