# Интерфейс и последовательность

Аудитория: человек, который хочет личную ленту на Mac и домашнем ТВ, без изучения сетевых терминов. Главный экран отвечает на три вопроса: что читать, как выглядит, где показывать. Дополнительные параметры открываются отдельно.

Палитра: broadcast red #C91429, ink #141C26, paper #F5F7FA, system white #FFFFFF и системный accent. Типографика: системный SF для основного текста; rounded только для часов предпросмотра; monospaced для числа сверки. Это сознательно близко к существующей Apple-стилистике проекта. Фирменный элемент - уменьшенная композиция собственной строки над редактором, а не большая декоративная картинка.

Главный экран: предпросмотр → название → состав строк → четыре оформления → телевизор. Каталог скрыт за выбранной строкой. RSS и Telegram не вынесены в разные технические вкладки: поле принимает @имя или HTTPS-ссылку. При каждом выборе видно число источников. В этой лаборатории первый запуск ещё не разделён на два отдельных шага; соответствие простому первому запуску стабильной версии требует отдельного переноса.

Экран телевизора: большая надпись, два понятных действия слева, QR справа. Никакого ручного набора адреса на пульте. Число сверки - только во время подтверждения доступа. Системное Android-разрешение выдаётся отдельно владельцем, не обходится приложением.

На iPhone: кнопка сканирования использует камеру приложения. На Mac: пока открывается изображение QR. Это временное различие, не завершённая идентичная простота Mac/iPhone. Следующее улучшение для Mac - видимый список найденных телевизоров с тем же подтверждением; сетевой Bonjour-транспорт уже предусмотрен.

Критерии перед переносом в стабильную версию: пользователь с чистыми настройками выбирает источники и запускает эфир за пять минут; iPhone 15 читает QR с расстояния обычного просмотра; все разрешения объяснены; окно не требует ручного IP/PIN; приложение явно различает черновик и применённый профиль; ошибка сети не выглядит успешным подключением.
