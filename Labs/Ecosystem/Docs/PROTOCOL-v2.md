# Stroka Link v2 - локальный протокол

## Владение профилем

TV - исполнитель и хранилище действующего профиля. Mac/iPhone - редакторы. Это отдельный протокол, несовместимый с текущим зеркалом Mac `/pair` → capability `/state` (v1). Установленная стабильная версия продолжает использовать v1.

Профиль: `schema:2`, имя, четыре стиля, верх/низ, высота, часы/дата/день недели, язык/часовой пояс, разделитель, пауза/уменьшение движения, базовая скорость и 1-4 строки. В строке: ID, название, kind (content/message/offline/markets), массив источников, сообщения, символы рынка. За счёт TV-рендерера профиль преобразуется в прежний `TVState schema:1` локально, без передачи кадров и без скринкаста.

## Сопряжение

1. Только открытое приложение ТВ предлагает подключение. При отсутствии разрешения Android на overlay QR не выдаётся.
2. ТВ генерирует постоянную EC P-256 TLS-идентичность в AndroidKeyStore. Закрытый ключ не экспортируется. Сертификат самоподписанный и не устанавливается в системное доверие телефона.
3. QR: `stroka://pair?v=2&host=<private IPv4>&port=<port>&fp=<SHA256 leaf DER>&nonce=<256-bit hex>&id=<16 hex>&service=Stroka-TV-<id>&exp=<unix seconds>`.
4. Приглашение действует 2 минуты и одноразово расходуется первым корректным запросом. QR не содержит постоянный секрет контроллера. Приложение проверяет формат, частный адрес, версию, срок и ключ. Требуется корректное системное время на устройствах.
5. Клиент использует TLS 1.2+, доверяет исключительно точному ключу из QR. Глобальных отключений ATS, проверки HTTPS-сертификатов RSS или системных предупреждений нет.
6. `POST /pair/request {nonce,name}` → 202 `{request,challenge}`. Имя ограничено; ТВ показывает запрос и число для сверки. QR не означает автоматического разрешения изменять ленту.
7. `POST /pair/result {request}` → `{state:pending|denied|approved, token?, id?, name?}`. Подтверждение производится на ТВ пользователем. Android foreground-service запускается из foreground-сценария ТВ; удалённый запрос не обходит запрет фонового запуска и overlay-разрешение.
8. Токен 256 бит передаётся только по проверенному TLS. На Apple хранится в Keychain `WhenUnlockedThisDeviceOnly`; на ТВ хеши разрешённых токенов зашифрованы AES-GCM с ключом AndroidKeyStore. Максимум 8 редакторов. Устаревшее приглашение/перезапуск QR не отзывает уже подтверждённые устройства; отдельная кнопка отзыва делает это явно.

## Редактирование

- `GET /profile`, `Authorization: Bearer <token>` → `{revision,profile,status}`.
- `PUT /profile`, тот же заголовок и `{revision,profile}` → новая редакция, либо 409 при устаревшей. Сервер проверяет номер и сохраняет файл атомарно. Нельзя молча затирать профиль, изменённый другим редактором.
- `POST /device/revoke` отзывает только текущий токен. Кнопка на ТВ отключает всех и останавливает сервис. Пользовательские профили не содержат ключей или токенов.
- Bonjour `_stroka._tcp` облегчает повторное подключение после смены адреса. Объявление Bonjour не является доказательством доверия: проверка сохранённого сертификата обязательна. Защита от смены адреса написана, физическая проверка DHCP ещё не выполнена.

## Ограничения

Только одна локальная сеть, без аккаунта, NAT traversal или внешнего прокси. До четырёх соединений, 5 секунд на чтение, заголовки 8 KiB, запрос 256 KiB, ответ клиента до 512 KiB, запросы сопряжения 8/мин. Нет CORS/browser API и удалённого администрирования Mac. QR и постоянные токены не логируются.

Загрузчик RSS принимает публичный HTTPS, запрещает IP-literal, localhost и приватные DNS-ответы, повторно проверяет перенаправления (до 3), ограничивает ответ 1 MiB. TLS-загрузчик подключается к проверенному DNS-ответу с исходным hostname для SNI/HTTPS-проверки. DTD/внешние сущности исключены. Внешняя дата published/pubDate не заменяется временем обновления или загрузки. Старше 24 часов, неизвестная и будущая дата не попадают в эфир. 48-часовое исключение ещё не перенесено.

Эта спецификация описывает прототип. Не прошедшие физическую приёмку участки перечислены в README и Validation/RESULTS.md; проверки не являются аудитом безопасности или одобрением магазина.
