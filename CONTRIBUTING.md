# Contributing and discussion

Bug reports and product/port proposals are welcome in Issues. Describe your platform, version, steps and expected/actual behavior. Remove tokens, personal content and private network details before posting.

Stroka is currently a public source preview with retained copyright, not a project under an open-source reuse grant. Source/contribution terms must be explicitly agreed before reusing code or accepting a substantive external code contribution. Do not assume MIT/Apache because a dependency uses that license.

For an agreed code change, keep the personal top/bottom ticker scope in CONSTITUTION.md, use isolated fixtures, run Scripts/check_release.py and the relevant diagnostics. Never commit profiles/caches/keys, and keep the autonomous-TV Lab separate from the current Mac mirror receiver. A build is not full device or store acceptance.
